# G0 prior-art collision audit

Inspected on 2026-09-28. This is a scoped audit of the proposed contract: **two independently useful, exact BF16 variants reconstructed before arithmetic in one grouped kernel that reuses a served anchor word for different activation vectors**. It is not a patent search or proof that no other implementation exists. CUDA throughput in these sources is not an M3 Max result.

**Decision:** No inspected paper section or released entry point demonstrates the complete grouped exact anchor-reuse contract. G0 may advance as a scoped novelty hypothesis. Any later source showing that contract reclassifies this work as reproduction or platform extension; source availability alone does not prove absence.

The released FM-Delta package path also uses `pickle` and PyTorch tensor conversion. FamilyTiles will not execute that package as an exact BF16 runtime baseline; its integer-delta mechanism is compared through the local CPU reference. All inspected CUDA/Hopper results remain qualitative comparisons. See `results/prior-art.json` for the full hashes, revisions, inspected locations and audit status.
