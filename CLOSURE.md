## Requirements for any separate future project

Specify the model(s), representation, device, context and concurrency, current measured live-memory bottleneck, required latency, and acceptable numerical or task-quality loss before implementation. If the target component occupies fraction `f` of baseline live memory and is reduced to fraction `c`, the approximate whole-memory saving before metadata, staging, and ownership costs is `f × (1 - c)`. This is an accounting rule, not a measured prediction. A future exact-weight consumer should demonstrate the raw-model numerical contract before codec integration; a quality-tolerant contract needs its own predeclared application metrics and matched baselines. No next workload has been selected here.
