# FamilyTiles

Research prototype. Exact family encoding is verified for the pinned Qwen2.5-1.5B base/Instruct pair: all 1,543,714,304 target BF16 words passed the CPU audit, and canonical active-weight bytes are **20.49% lower** than native exact sharing. The tested M3 Max consumers did not meet the required numerical or latency contract. Corrected full-model fused inference, the full C3 corpus, and process-peak capacity are **not validated**. Use the stock/native path with the original checkpoints for this deployment.

The [closure status](CLOSURE.md) separates the verified representation, closed consumer program, and untested alternatives. The [original result](RESULTS.md), [native-first continuation](results/continuation/CONTINUATION_RESULTS.md), and [final epilogue check](results/epilogue-check/FINAL_DECISION.md) preserve the experiment history and raw-record links.

There is no ordinary inference command in the package CLI. The cached-decoding replay requires an explicit `--mode`; other model scripts in `tools/` are named research diagnostics. Compressed and custom execution remains experimental and did not pass admission. A compressed-only artifact does not provide the original native checkpoints needed by the stock path. Conversion, exact-decoder verification, and research reproduction remain available; model weights and converted artifacts stay outside Git.

The [research specification](docs/superpowers/specs/2026-09-28-familytiles-design.md), [gated implementation plan](docs/superpowers/plans/2026-09-28-familytiles.md), [full-family ledger](results/conversion/ledger.json), [frozen codec policy](results/survey/frozen-policy.json), and [prior-art audit](prior_art.md) remain available. Reproduction commands in the archived reports are manual research procedures, not required close-out work.
